# 飞雪影视 FeixueTV

一款面向 Android TV / 电视盒子的影视播放应用，支持多数据源聚合搜索、最优线路播放、手机扫码推送搜索，兼容遥控器操作。

## 功能特性

### 浏览与搜索
- 首页推荐影片（优先展示站点后台推荐 `vod_level` 标记，回退评分热度排序）
- 分类浏览与筛选：年份、地区、排序（最近更新 / 评分 / 播放量）
- 多数据源聚合搜索：并发查询所有启用的数据源，结果交错合并、标注来源，左侧可按源过滤
- 手机扫码推送搜索：电视显示二维码，手机扫码输入关键词，电视自动搜索（同一局域网）

### 播放
- 播放内核：ExoPlayer / IJK / 外部播放器
- 硬解码 / 软解码切换
- 自动测速选择最优线路，也可手动切换线路
- 声道（音轨）、内嵌字幕、分辨率（多码流轨道）选择
- 播放速度 0.75x ~ 2.0x、画面比例（适应 / 填充 / 裁剪）
- 片头 / 片尾跳过秒数设置
- 底部控制栏：进度条拖动、上下集、选集、重播、重试

### 数据源
- 支持苹果 CMS（Apple CMS）JSON 接口（`api.php/provide/vod/at/json`）
- 新增、编辑、删除、设为当前、启用 / 停用聚合
- 批量订阅导入：JSON 数组、`名称,地址` 多行文本、纯地址列表

### 其他
- 播放历史（自动记录集数，可续播、删除、清空）
- 我的收藏（详情页加入收藏，可取消、清空）
- 常规设置：默认内核 / 解码 / 倍速 / 片头片尾 / 聚合开关 / 推荐位开关
- 在线更新：与 GitHub 最新 Release 对比版本，显示下载进度与速度，下载后自动调起安装

## 使用说明

### 遥控器操作
- 方向键：移动焦点；OK 键：确认
- 播放页：OK / 下方向键呼出控制栏，左右方向键快进快退，菜单键显示 / 隐藏控制栏，返回键退出

### 数据源订阅格式
```
[{"name":"示例源","url":"http://example.com/api.php/provide/vod/at/json"}]
```
或
```
示例源,http://example.com/api.php/provide/vod/at/json
```

### 在线更新
设置 → 系统 → 检查更新。应用会请求本仓库的 `releases/latest` 接口比较版本号，发现新版本后可下载 APK（显示进度与速度），完成后自动调起系统安装器。

## 构建

- Kotlin + 原生 View，minSdk 21，targetSdk 35
- 依赖：Media3 ExoPlayer、IJKPlayer、Retrofit / OkHttp / Gson、Coil、ZXing

```bash
./gradlew assembleDebug
```

## 发布

版本发布于本仓库 Releases，APK 作为附件上传，客户端通过该接口检测更新。
